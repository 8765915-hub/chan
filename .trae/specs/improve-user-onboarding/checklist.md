# Checklist

## 首次启动引导
- [x] 首次进入（无 guide_seen 标记）展示 3 屏引导页，可滑动/跳过
- [x] 点击"开始使用"写入标记并进入首页；再次进入不再展示

## 首页地图空状态与定位降级
- [x] 地图无标记且加载完成时显示空状态卡片，按钮跳转打卡页
- [x] 定位失败时页面正常渲染，显示可点击提示条且可重试
- [x] 定位成功后地图正常展示标记与定位按钮

## 打卡登录前置与草稿续传
- [x] 未登录提交时跳转登录页，登录后返回打卡页且已填内容保留
- [x] 退出打卡页再进入自动回填草稿；提交成功/清空后草稿删除
- [x] 媒体临时路径失效时自动清空媒体部分并提示，不报错

## 打卡提交即时反馈
- [x] 提交成功后展示积分预估（美景10/行为15/公益20）与审核流程提示

## 审核结果订阅消息
- [x] 配置模板 ID 后提交打卡请求订阅授权；审核通过/驳回后用户收到通知（代码就绪，需填入模板 ID 后启用）
- [x] 未配置模板 ID 时，提交与审核流程正常走通、不报错
- [x] 订阅消息模板 ID 集中在 src/config.js 配置

## 首次打卡奖励
- [x] 用户首次打卡审核通过时获得基础积分 + 5 首卡奖励
- [x] 非首次通过只发基础积分，不重复发放

## 官方种子内容
- [x] 管理员可在审核页一键导入 3 条示例内容，地图与广场立即可见
- [x] 重复导入不产生重复数据
- [x] 非管理员调用种子接口返回 403

## 空状态文案引导
- [x] 首页与广场空状态均有明确行动引导文案与可执行操作
