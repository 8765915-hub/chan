# 城市微光 (City Glimmer)

**打卡城市地标，集齐专属印章，点亮你的足迹地图。**

「城市微光」是一款基于微信小程序的全国地标/景区集章打卡产品：内置 **186 个覆盖全国 34 个省级行政区的打卡点**（5A/4A 景区、知名地标、特色街区），用户到点拍照打卡即可点亮专属印章，集齐一个省的全部印章解锁该省系列徽章，生成打卡海报分享给好友。

**一句话定位**：全国城市地标集章打卡小程序，靠收集 + 排行榜 + 海报分享裂变。

---

## 🌟 核心功能

### 1. 🗺️ 打卡地图（首页）
- 全国 186 个预置打卡点展示在地图上，支持按省份筛选、附近模式（50km 内）；
- 点击打卡点查看名称、分类、简介、打卡人数，一键跳转打卡。

### 2. 📸 打卡集章
- **三种打卡模式**：
  - 实地打卡（+20 分）：需在打卡点 1.5km 范围内（距离自动校验）；
  - 回忆打卡（+10 分）：之前去过，补打卡；
  - 云打卡（+5 分）：云游集章，无需到现场；
- 每个用户每个打卡点只能收集一次印章（防刷）；
- 预置打卡点提交即通过（自动内容安全检测），即时发积分、点亮印章；
- 图片自动压缩 + 微信内容安全检测（文本/图片）。

### 3. 🕹️ 我的印章（印章册）
- 收集进度总览（已收集/总数）；
- **34 个省级系列**（如"京城风华""岭南风情"），集齐一个省解锁该系列徽章；
- 每个系列可展开查看省内各打卡点的收集状态；
- 最近收集时间线。

### 4. 🏆 集章榜
- 本周集章榜（枚）/ 本周积分榜 / 总积分榜，前三名领奖台。

### 5. 🎨 打卡海报
- 打卡成功后一键生成专属海报（照片 + 印章 + 打卡点名），保存到相册或分享好友/朋友圈，作为裂变钩子。

### 6. 👮 管理员
- 保留移动端审核（用户新增打卡点/举报内容走审核）；
- 管理员可一键导入 186 个预置打卡点（`/seed/spots`，按 code 去重，可重复调用）。

## 🛠️ 技术栈

- **前端**：UniApp + Vue 3 (Composition API) + Pinia + Vite
- **后端**：微信小程序云开发
  - 云函数 `api`：业务接口（登录、打卡点、打卡、榜单、印章册、审核、商城）
  - 云函数 `checkContent`：文本/图片内容安全检测
  - 云数据库：`users` / `reports` / `likes` / `spots` / `redemptions`
  - 云存储：打卡照片/视频

```
  │   ├── feed/            # 广场（最新/热门打卡动态）

  └── utils/               # request / series（省份系列名）/ watermark
```

## 🚀 部署步骤

### 1. 环境准备
- 安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html) 或 VS Code；
- 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
- 注册微信小程序账号，开通**云开发**。

> **Node 版本要求**：**推荐 Node 18 LTS**（本项目的 uni-app alpha 2024-05 版本 + Vite 5.2.8 均以 Node 18 为目标，`vite@5.2.8` 要求 `^18 || >=20`）。Node 20 亦可；**不建议 Node 22**。
>
> **`npm install` 报错怎么办**：
> 1. 若报 **peer 依赖冲突（ERESOLVE）**：执行 `npm install --legacy-peer-deps`，或在项目根目录新建 `.npmrc` 写入 `legacy-peer-deps=true`；
> 2. 若卡在 **canvas / node-gyp / gyp ERR**：这是旧版 `canvas` 原生模块在 Node 22 上无预编译二进制导致的（本项目已从 `package.json` 移除 `canvas`，它仅用于 `scripts/generate-badges.js` 生成徽章图片，徽章 PNG 已内置在 `src/static/badges/`）。若你仍在旧版本上遇到，请同步最新的 `package.json` 后删除 `node_modules` 重新安装；
> 3. 项目**没有 package-lock.json**，不同 npm 版本解析结果可能不同；首次安装成功后请保留生成的 `package-lock.json` 以便后续可复现。

### 2. 运行项目
```bash
npm install
npm run dev:mp-weixin   # 或用 HBuilderX 运行到微信开发者工具
```

### 3. 云开发配置（关键）
1. **云环境**：在 `src/App.vue` 中确认 `wx.cloud.init({ env: '你的环境ID' })`；
2. **创建集合**：云开发控制台 → 数据库 → 创建 `users`、`reports`、`likes`、`spots`、`redemptions`；
3. **部署云函数**：
   - `cloudfunctions/api` 右键 → 上传并部署：云端安装依赖（建议超时 20s）；
   - `cloudfunctions/checkContent` 右键 → 上传并部署：云端安装依赖，并在 `config.json` 确认 openapi 权限；
4. **配置 AppID**：`src/manifest.json` → 微信小程序配置 → 填入你的 AppID。

### 4. 导入打卡点数据（二选一）
- **方式 A（控制台导入，推荐）**：
  1. 云开发控制台 → 数据库 → `spots` 集合 → **导入**；
  2. 选择 **`cloudfunctions/api/spots-seed.ndjson`**（**JSONLines 格式，每行一个打卡点**。注意：微信控制台导入只认 JSONLines，不认 JSON 数组，所以别选 `spots-seed.json`）；
  3. 冲突处理模式选 **Insert**（若之前导入过导致重复，可先全选删除再导入）。
- **方式 B（接口导入）**：把自己设为管理员后调用导入接口
  1. 首次登录小程序，然后在云开发控制台的 `users` 集合中，把自己的记录 `role` 字段改为 `admin`；
  2. 调用云函数 `api` 的 `url: '/seed/spots'`（POST），内部读取 `spots-seed.json` 导入；
  3. 返回"新增 186 个"即成功，重复调用会自动跳过（按 code 去重）。

> ⚠️ **坐标说明**：种子数据的经纬度为近似值（误差约 0.01°~0.05°）。实地打卡距离校验半径为 **1.5km**（可改 `cloudfunctions/api/index.js` 中的 `CHECKIN_RADIUS_KM`），如需更严格的校验，请用地图工具复核各打卡点坐标后导入。

### 5. 权限说明
- `manifest.json` 已声明 `scope.userLocation`（定位用于实地打卡校验）；
- 腾讯位置服务 key（`src/store/modules/location.js` 与 `manifest.json` 中的 `LWHBZ-...`）为示例，建议替换为你自己的 key（[腾讯位置服务](https://lbs.qq.com/)）；
- 订阅消息模板 ID（`cloudfunctions/api/index.js` 与 `src/config.js` 中）为审核/成就通知用，可留空跳过。
